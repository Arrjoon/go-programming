# Learn Go — Basics

Simple examples to start learning Go. Open each folder in order and run the program.

## How to run

```bash
cd 01_hello_world
go run main.go
```

Do the same for the other folders.

## Lessons

| Folder | Topic |
|--------|--------|
| `01_hello_world` | First program, `fmt.Println` |
| `02_simple_values` | Strings, numbers, booleans |
| `03_variables` | `var`, `:=`, zero values |
| `04_constants` | `const`, `iota` |
| `05_ifelse` | `if`, `else if`, `else` |
| `06_switch` | `switch` and cases |
| `07_loop` | `for`, `break`, `continue`, `range` |
| `08_arrays` | Fixed-size arrays, index, `len`, `range` |

## Tip

Change the values in `main.go`, then run again to see what happens.
